# Multi-Agent Collaboration Protocol

You are working on a shared software project with another AI coding agent.

## Mandatory rules

1. Before modifying any file, inspect the current Git status and recent changes.
2. Check the shared task board for existing assignments and file ownership.
3. Never modify a file currently reserved by another agent without explicit coordination.
4. Do not overwrite, revert, or remove another agent's changes.
5. Keep changes focused on your assigned task.
6. Before committing, inspect your diff carefully.
7. Never force-push or overwrite shared branches.
8. If you need to modify a file owned by another agent, request coordination first.
9. After completing a task, report:
   - Files modified
   - Features implemented
   - Dependencies or API changes
   - Remaining issues
10. Pull and review shared changes before starting new work.

## Priority

Preserve the work of both agents over completing tasks quickly.

If a conflict occurs, stop and coordinate instead of guessing.
